# Advent of Code 2025

[https://adventofcode.com/2025](https://adventofcode.com/2025)

## Prerequisites

* [.NET 9.0](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)

## Building

```sh
dotnet restore
dotnet build
```

## Testing

```sh
dotnet test
```

## Running

```sh
cd ./aoc2025
dotnet run
```
